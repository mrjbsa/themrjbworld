Settings (zaroorat par)

Client ID wohi daalein jo aapke admin panel mein hai. Is page ka address (origin) Google Cloud Console mein "Authorized JavaScript origins" mein hona chahiye.

1. YouTube channel

Home page ke "Visit channel" button ka link. Khali chhorenge to site ki settings wala channel link use hoga.

2. Home page videos (3D ring)

Latest projects ke neeche ghoomne wali videos. 5 recommended, zyada se zyada 8. Title optional hai, khali ho to "Watch now on YouTube" likha aata hai.

3. Projects (apps / websites) ki videos

Jis project ke saamne link daalenge, uske card par "Watch now" aur detail page par video thumbnail aayega. Khali = kuch nahi dikhega.

4. Live websites ki videos

Same cheez live websites ke liye.

Ek dafa ka kaam: File ID site mein daalein

Site ko pata hona chahiye ke videos kahan se leni hain. Yeh ID script.js mein VIDEOS_FILE_ID ke saamne paste karke site dobara upload karein. Sirf pehli dafa karna hai, baad ki saari tabdeeliyan khud-ba-khud nazar aayengi.
